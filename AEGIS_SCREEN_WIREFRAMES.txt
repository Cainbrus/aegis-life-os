DESIGN SYSTEM NOTES:
--------------------------------------------------------------------------------
    Theme:          Dark mode (slate/charcoal backgrounds)
    Primary Color:  Cyan (#00FFFF / #06B6D4)
    Accent Color:   Purple (#8B5CF6)
    Alert Color:    Red (#EF4444)
    Success Color:  Green (#10B981)
    Typography:     Clean sans-serif (Inter, SF Pro, or similar)
    Style:          Modern, minimal, "alive" feeling
    Corners:        Rounded (16-24px radius on cards)

DESIGN NOTES:
--------------------------------------------------------------------------------
    • Cards should feel like Google Discover - not a rigid list
    • High priority cards are wider and have warning styling
    • Each card type has a color-coded icon and subtle left border
    • Feed is vertically scrollable
    • Bottom nav is floating with blur backdrop
    • MATE avatar in top right - tappable to open chat


INTERACTIONS:
--------------------------------------------------------------------------------
    • Swipe left on card = dismiss
    • Swipe right on card = mark as done
    • Tap card button = perform action
    • Long press card = more options
    • Tap MATE avatar = open AI chat

DESIGN NOTES:
--------------------------------------------------------------------------------
    • Modal appears over blurred background
    • Friendly, apologetic tone - NOT an error message
    • Logo with question mark indicates learning mode
    • Buttons are full-width, easy to tap
    • Options are simple, plain language
    • Small escape link at bottom for accidental undos


INTERACTIONS:
--------------------------------------------------------------------------------
    • Tap option = AI learns and modal closes
    • Tap outside modal = dismiss (no learning)
    • Tap small link = confirm original action was correct


================================================================================
                    ADDITIONAL NOTES FOR DESIGNERS
================================================================================

ANIMATIONS:
    • Cards should slide in smoothly when loading
    • Pop-ups should fade in with slight scale (0.95 → 1.0)
    • Buttons should have subtle press feedback
    • MATE avatar should have gentle pulse/glow
    • Data streams in background should flow continuously

ACCESSIBILITY:
    • All text should meet WCAG contrast ratios
    • Touch targets minimum 44x44px
    • Support for dynamic text sizes
    • Screen reader labels on all interactive elements

RESPONSIVE:
    • Designs should work on phones 375px-428px wide
    • Tablet versions can show 2-column layouts
    • Desktop web version for security dashboard
